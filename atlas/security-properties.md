# Security Property Atlas

| Property family | Representative question |
|---|---|
| Authorization | Can an unauthorized actor mutate critical state? |
| Accounting | Does value conservation hold across conversions? |
| Solvency | Are liabilities bounded by available assets? |
| Lifecycle | Can a valid lifecycle operation permanently destroy control? |
| Replay | Can consumed authorization become valid again? |
| Integrity | Can state transition outside the protocol model? |
| Availability | Can an actor force an unrecoverable operational state? |
| Cross-domain | Do source and destination enforce equivalent trust assumptions? |
