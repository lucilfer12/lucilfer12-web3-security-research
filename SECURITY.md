# Security Policy
This repository is a research archive and laboratory. It may contain intentionally vulnerable toy models and sanitized public case studies.
Never submit credentials, tokens, private keys, private client material, confidential bounty-platform content, unreleased exploit details, personal data, or material that violates a disclosure agreement.
Research records use explicit classifications such as public, sanitized, under-review, private, validated, fixed, duplicate, informative and experimental.
The classification describes evidence status; it is not a severity score.
