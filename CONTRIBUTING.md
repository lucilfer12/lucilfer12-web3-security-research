# Contributing
Contributions should improve research quality, reproducibility, or clarity.
1. State the hypothesis or security property.
2. Define the threat model and trust boundaries.
3. Provide deterministic reproduction where practical.
4. Separate observation from interpretation.
5. Record assumptions and limitations.
6. Add regression coverage for demonstrated failures when practical.
7. Preserve provenance for external incidents and public sources.
8. Never add confidential or unauthorized material.
Prefer a small fully reproducible experiment over speculative volume.
