# Disclosure Classification
- public: safe for public research
- sanitized: public research with sensitive details removed
- under-review: disclosure decision is not final
- private: intentionally excluded from public technical detail
- validated: independently accepted or confirmed
- fixed: remediation is documented
- duplicate: triage classified it as a duplicate
- informative: triage classified it as informative
- experimental: research hypothesis or laboratory result
Disclosure state and triage state are distinct dimensions.
