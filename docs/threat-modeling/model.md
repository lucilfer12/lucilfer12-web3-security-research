# Threat Model
| Dimension | Questions |
|---|---|
| Assets | What value or security property is protected? |
| Actors | Who can interact with the system? |
| Privilege | What permissions are required? |
| Trust boundaries | Where does trust change? |
| Entry points | Which calls/messages cross the boundary? |
| State | Which state variables matter? |
| Dependencies | Which external contracts, keys, or services are assumed? |
| Preconditions | What must already be true? |
| Adversarial input | What can the actor control? |
| Failure | Which property becomes false? |
| Impact | What changes for users or the protocol? |
| Mitigation | Which property is restored? |
