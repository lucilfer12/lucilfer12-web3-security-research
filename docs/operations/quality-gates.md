# Research Quality Gates

Before publication:

- Scope is explicit.
- Threat actor is explicit.
- Required privilege is explicit.
- Security property is testable or precisely reasoned.
- Preconditions are enumerated.
- Impact is measured in correct units.
- Reproduction is deterministic where practical.
- Mitigation addresses the underlying property.
- Regression coverage exists where practical.
- Disclosure state is accurate.
- Private information is excluded.
- Claims are separated from assumptions and interpretations.
