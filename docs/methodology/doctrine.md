# Security Research Doctrine
- Security is a property of a system under an adversarial model.
- Code is evidence; prose is explanation.
- Privilege is part of impact analysis.
- Technical weakness and production exploitability are different claims.
- Reproducibility outranks spectacle.
- Negative results are valuable when the method is explicit.
- Disclosure status is part of the artifact.
- Generalized patterns remain traceable to evidence.
Do not inflate severity, loss, exploitability, uniqueness, or disclosure status.
